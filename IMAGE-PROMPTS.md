# ND Derma Med Spa — AI Image Generation Prompts

## How to Use (Free — No API Needed)

### Best Free Tools (Recommended in Order)
1. **Bing Image Creator** — go to bing.com/images/create — completely free with any Microsoft/Outlook account — uses DALL-E 3
2. **Ideogram.ai** — free tier, great for realistic photos, go to ideogram.ai
3. **Leonardo.ai** — free tier (150 tokens/day), go to app.leonardo.ai → Image Generation

### Tips
- Copy each prompt below exactly as written — they are already optimized
- If the result doesn't look right, re-roll (generate again) — free tools have unlimited tries
- Download at highest resolution available
- Save images using the filename suggested (e.g. `hero-bg.jpg`) so they match the website paths below
