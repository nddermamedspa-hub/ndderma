📋 QUICK START (Copy & Paste Commands)

STEP 1: GET CREDENTIALS (5 min)
─────────────────────────────────
1. Go to: https://dashboard.squareup.com
2. Click: Developers → API Keys
3. Copy: Production Access Token (sq_live_...)
4. Copy: Application ID
5. Navigate to: Locations
6. Copy: Location ID for your med-spa

STEP 2: INSTALL DEPENDENCIES (2 min)
──────────────────────────────────────
$ pip install squareup pandas python-dotenv requests

STEP 3: CREATE .ENV FILE (2 min)
──────────────────────────────────
$ cp .env.example .env

Then edit .env with your credentials:
SQUARE_ACCESS_TOKEN=sq_live_YOUR_TOKEN
SQUARE_APPLICATION_ID=YOUR_APP_ID
SQUARE_LOCATION_ID=YOUR_LOCATION_ID
BRONZE_MONTHLY_PRICE=79.00
SILVER_MONTHLY_PRICE=149.00
GOLD_ANNUAL_PRICE=1299.00

STEP 4: TEST CONNECTION (1 min)
────────────────────────────────
$ python scripts/test_connection.py

Should show:
✓ Connection successful!
✓ Merchant: ND Derma Med Spa

STEP 5: RUN FULL SETUP (5 min)
─────────────────────────────────
$ python scripts/full_setup.py

What it creates:
✓ 45+ aesthetic services
✓ 3 membership plans (Bronze/Silver/Gold)
✓ Staff members (optional)
✓ Webhooks (optional)

STEP 6: VERIFY IN SQUARE DASHBOARD
──────────────────────────────────────
1. Go to: https://dashboard.squareup.com
2. Check: Catalog → Items (should show 45+ services)
3. Check: Subscriptions → Plans (should show 3 memberships)

🔐 SECURITY CHECKLIST

✅ DO:
   • Keep .env file private
   • Never commit to Git
   • Use production credentials only
   • Rotate API keys monthly
   • Keep access token secure

❌ DON'T:
   • Hardcode credentials in scripts
   • Share .env via email
   • Use same key for dev/prod
   • Commit to GitHub
   • Share with unauthorized users

Add to .gitignore:
.env
*.env
secrets.json
